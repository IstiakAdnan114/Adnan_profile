# Research portfolio

A plain HTML/CSS website. No installation, build step, database, or API keys.

## Preview
Open index.html in your browser.

## Publish on GitHub Pages
1. Create a new public GitHub repository (for example research-portfolio).
2. Upload index.html, style.css, .nojekyll, and the images folder to its root. Upload the contents, not the enclosing folder.
3. Go to Settings → Pages.
4. Select Deploy from a branch, main, and /(root), then Save.
5. GitHub displays the live address when deployment completes: https://IstiakAdnan114.github.io/research-portfolio/ (if that is the repository name).

## Edit
Edit text and links directly in index.html. Edit colors and layout in style.css. All image paths are relative, so the site also works under a repository URL. The contact link opens the visitor's email application. The CV opens the existing Google Drive document.
